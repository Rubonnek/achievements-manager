# Achievements Manager

<img src="icon.svg" width="128" height="128">

![GitHub Release](https://img.shields.io/github/v/release/Rubonnek/achievements-manager?label=Current%20Release)
![Github Downloads](https://img.shields.io/github/downloads/Rubonnek/achievements-manager/total?logo=github&label=GitHub%20Downloads)

A flexible and efficient achievement system for the Godot Game Engine.

## :star: Features

- :trophy: Progress-based achievements with customizable target values
- :lock: Hidden achievements that remain concealed until unlocked
- :key: String IDs for integration with external platforms (Steam, Epic Games, etc.)
- :memo: Custom metadata support for extended achievement properties
- :bell: Signal-based notifications for unlock and progress update events
- :zap: Optimized storage with efficient dictionary-based internal structure
- :mag: Built-in debugger viewer for real-time achievement monitoring
- :package: Both low-level optimized accessors and high-level wrapper objects
- :art: Easy to customize -- bring your own GUI nodes

## :zap: Requirements

- Godot 4.2.1+

## :rocket: Getting Started

- Clone/[download](https://github.com/Rubonnek/achievements-manager/archive/refs/heads/master.zip) the repository and check out the demos!

## :package: Installation

[Download](https://github.com/Rubonnek/achievements-manager/archive/refs/heads/master.zip) or clone this repository and copy the contents of the
`addons` folder to your own project's `addons` folder, and enable the `Achievements Manager` plugin in the Project Settings.
